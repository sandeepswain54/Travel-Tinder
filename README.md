# 🌍 Travel Tinder App

![Travel Tinder App](assets/tinder.png)

A swipe-based travel matching app that helps users find compatible travel buddies based on destination, travel dates, and interests.

## ✨ Features
- Tinder-style swipe matching
- Match travelers by destination & interests
- Clean and intuitive UI
- Designed for solo travelers & explorers


## 🎯 Why Travel Tinder?
Traveling alone isn’t always fun or safe. Travel Tinder connects like-minded travelers so they can explore destinations together, share experiences, and travel smarter.
